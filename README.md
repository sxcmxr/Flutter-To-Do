## Introduction

This project is a basic **To Do List** application built with [Flutter](https://flutter.dev/). Users can add, mark as done, and remove tasks on the list.

## Features

- **Add tasks** by typing in a text field and pressing the "Add" button (or an equivalent widget).
- **View tasks** in a scrollable list.
- **Mark tasks as completed** (tasks become crossed out and checkbox changes state).
- **Delete tasks** from the list (use the trash bin icon).

## Requirements

- Flutter SDK (2.x or above recommended).
